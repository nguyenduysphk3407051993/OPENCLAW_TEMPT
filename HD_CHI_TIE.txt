Bước 1: Tải mã nguồn mới nhất từ Github
--------------------------------------------------
[Cách 1 - Khuyên dùng] Sử dụng HTTPS (Nhanh gọn, không cần cài đặt SSH Key):
    git clone https://github.com/nguyenduysphk3407051993/OPENCLAW_TEMPT.git

[Cách 2 - Bảo mật cao] Sử dụng giao thức SSH:
    Nếu bạn muốn dùng SSH, bạn phải thiết lập khóa bảo mật trên VPS theo các bước sau:
    a. Tạo khóa SSH mới (nếu VPS chưa có):
       Chạy lệnh: ssh-keygen -t rsa -b 4096 -C "email_cua_ban@gmail.com"
       (Ấn Enter liên tục 3 lần để bỏ qua các tùy chọn phụ, không cần nhập mật khẩu)
    b. Xem và Copy đoạn mã Public Key vừa tạo:
       Chạy lệnh: cat ~/.ssh/id_rsa.pub
       (Bôi đen và Copy toàn bộ đoạn text hiện ra, bắt đầu bằng chữ "ssh-rsa...")
    c. Khai báo khóa với Github:
       Truy cập Github.com -> Settings -> SSH and GPG keys -> Bấm "New SSH key".
       Dán đoạn mã vừa copy vào khung "Key" và lưu lại.
    d. Tiến hành tải code trên VPS:
       Chạy lệnh: git clone git@github.com:nguyenduysphk3407051993/OPENCLAW_TEMPT.git

Sau khi tải xong mã nguồn, truy cập vào thư mục:
    cd OPENCLAW_TEMPT

(Nếu thư mục đã có sẵn mã nguồn, chỉ cần chạy: git pull origin main)

Bước 2: Tận dụng file môi trường có sẵn
--------------------------------------------------
Hệ thống đã có sẵn file `.env.edutechnd.org` chứa toàn bộ API Key và Token của bạn.
Sao chép nội dung file này sang file `secrets.env` để script khởi tạo có thể đọc được:
    cp .env.edutechnd.org secrets.env

Bước 3: Chạy script khởi tạo hệ thống
--------------------------------------------------
Vì file `secrets.env` đã được chuẩn bị đầy đủ, bạn chỉ cần cấp quyền và chạy script 1 lần duy nhất.
Script sẽ tự động sinh ra docker-compose.yml, Dockerfile và các cấu hình liên quan:
    chmod +x init.sh
    bash init.sh

Bước 4: Build và khởi động Docker
--------------------------------------------------
Sử dụng tham số `--no-cache` để đảm bảo hệ thống build sạch 100%, không bị dính cache cũ:
    docker compose build --no-cache
    docker compose up -d

Bước 5: Kiểm tra trạng thái hoạt động
--------------------------------------------------
Chờ khoảng 10-15 giây để Database (Postgres) khởi động. Xem log để xác nhận bot đã đăng nhập thành công vào Telegram/Zalo/Discord:
    docker compose logs -f openclaw-gateway

(Bấm Ctrl + C để thoát khỏi chế độ xem log)
